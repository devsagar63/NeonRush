# 🌌 NeonRush — Neon Endless Runner

**NeonRush** is a futuristic neon-themed endless runner game built using **HTML, CSS, and JavaScript**. Dodge obstacles, jump across a glowing cyberpunk track, and push your limits as the speed and challenge increase.

Experience a fast-paced arcade game with vibrant neon visuals, smooth controls, and an immersive futuristic atmosphere.

## 🎮 Features

- 🌃 **Neon Cyberpunk UI** — Futuristic visuals with glowing effects.
- 🏃 **Endless Running Gameplay** — Keep running and avoid incoming obstacles.
- 🦘 **Jump Mechanics** — Jump to overcome barriers and survive longer.
- 📏 **Distance Tracking** — Track how far you travel during each run.
- 🏆 **Score System** — Earn points as you progress.
- 💾 **Best Record** — Track your personal best score.
- 💥 **Game Over Screen** — View your final score and restart the game.
- 📱 **Responsive Controls** — Play using keyboard or touch controls, where supported.
- ⏸️ **Pause and Resume** — Take a break and continue your run, where supported.
- 🔊 **Sound Effects** — Enjoy audio feedback during gameplay, where supported.
- ⚡ **Optimized Rendering** — Designed for smooth gameplay in modern browsers.

## 🛠️ Built With

- **HTML5** — Game structure
- **CSS3** — Styling, animations, and neon effects
- **JavaScript** — Gameplay logic, controls, scoring, and rendering
- **Canvas API** — Graphics and game rendering, if used by the implementation

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/devsagar63/NeonRush.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd NeonRush
```

### 3. Run the game

Open `index.html` in your web browser.

For the best development experience, you can use the **Live Server** extension in Visual Studio Code.

No installation or build process is required for this vanilla HTML, CSS, and JavaScript project.

## 🕹️ How to Play

- **Spacebar / Up Arrow** — Jump
- **Mouse or touch controls** — Use the on-screen controls if available.
- **Pause button** — Pause or resume the game if implemented.
- **Restart button** — Start a new run after game over.

**Objective:** Avoid obstacles, survive as long as possible, cover the greatest distance, and beat your best score!
